GoLogin Integration
What is GoLogin? 🌐

GoLogin is an anti-detect browser that creates isolated browser profiles — each with a unique fingerprint (IP, canvas, fonts, etc.). Twitter can't detect that multiple accounts come from the same device.

Using GoLogin profiles is the safest way to connect Twitter accounts — it avoids automation flags and Error 226.

→ Open GoLogin website · → Get API token
How to connect (3 steps)
  1. Create a GoLogin account and add a browser profile with your Twitter account logged in
  2. Go to GoLogin → Settings → API and copy your API token
  3. Paste the token below → click Save → click Load Profiles → select your profile → Import
Import Twitter accounts directly from your GoLogin profiles. The profile must have Twitter logged in inside GoLogin.

Find your token in GoLogin → Settings → API

Username will be detected from cookies automatically if left empty.

🔑 GetX API
Outreach search uses GetXAPI (Bearer token). This is not your Twitter password.
What is GetX API? 🔍

GetX is a Twitter data API that lets you search for tweets, profiles, and conversations at scale — much faster than manual browsing and without rate limits from the official Twitter API.

This app uses GetX to find leads: people who are talking about topics relevant to your product.

→ Open GetX website · → Get API key
How to get the key (2 steps)
  1. Sign up on getxapi.com and choose a plan (there is a free tier)
  2. Copy your Bearer token from the dashboard and paste it in the field below
